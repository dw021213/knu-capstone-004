# 제주 안전지도 지도 표현 목업

제주 전역의 정보를 지도에 표현하는 방식 3가지를 비교하는 정적 HTML 목업입니다. 현재 저장소의 계획 단계인 React·Go 웹앱과는 별개로 실행됩니다.

## 실행 방법

Python 3만 있으면 됩니다. 저장소 루트에서 다음 명령을 실행하세요.

```bash
python3 -m http.server 8765
```

브라우저에서 아래 주소 중 하나를 엽니다.

| 목업 | 주소 |
| --- | --- |
| 지역별 위험 점수 | <http://localhost:8765/mockups/01-score-map.html> |
| 기상 위험장 | <http://localhost:8765/mockups/02-weather-field.html> |
| 안전 자원 분포 | <http://localhost:8765/mockups/03-safety-elements.html> |

서버 종료는 터미널에서 `Ctrl+C`를 누릅니다. 별도 패키지 설치, API 키, 빌드 과정은 필요하지 않습니다. D3와 지도 데이터는 `assets/`에 포함되어 있습니다.

## 페이지 설명

| 파일 | 표현 방식과 조작 | 데이터 상태 |
| --- | --- | --- |
| [01-score-map.html](01-score-map.html) | 읍·면 및 시내 동지역에 예시 위험 점수를 색과 숫자로 표시합니다. 종합·재난/날씨·교통·범죄 항목을 전환하고 지역을 선택할 수 있습니다. 확대하면 리·동 단위 예시 점수가 나타납니다. | 모든 점수와 위험 구간은 시각화 비교용 예시입니다. 실제 위험도 모델과 연결되지 않았습니다. |
| [02-weather-field.html](02-weather-field.html) | 행정구역별 색칠 대신 중심에서 퍼지는 강수·강풍 영향 범위를 표시합니다. 기상 요소 전환, 위험 중심 선택, 확대·축소, 경계·읍면 이름 표시 전환을 제공합니다. | 위험 중심의 위치·강도·반경은 시뮬레이션입니다. 실시간 기상 API와 연결되지 않았습니다. |
| [03-safety-elements.html](03-safety-elements.html) | 경찰·소방·편의점 자원을 유형별 점으로 표시합니다. 유형을 켜고 끄거나 읍면동을 선택해 확대하고 시설점을 선택할 수 있습니다. | 공개 자료의 시설 목록과 편의점 좌표를 반영했습니다. 경찰·소방 점은 읍면동 단위 개략 위치이며 편의점의 현재 영업 여부·정확한 출입구 위치는 보증하지 않습니다. 안전도나 보호 반경을 뜻하지 않습니다. |

세 페이지 모두 제주 본섬과 우도를 중심으로 보여주며, 참고 지도 범위에 맞춰 추자면은 제외했습니다.

## 파일 구성과 출처

- `assets/d3.min.js`: 지도 투영과 조작에 쓰는 D3 v7.9.0 번들.
- `assets/jeju-data.js`, `assets/jeju-emd.geojson`: [Local_HangJeongDong](https://github.com/raqoon886/Local_HangJeongDong)의 제주 행정동 경계 가공본과 원본 사본.
- `assets/jeju-ri-data.js`: [mapcn-kr](https://github.com/DevMinGeonPark/mapcn-kr)의 2026년 법정리 경계에서 추자면을 제외한 가공본. 원출처는 행정안전부입니다.
- 3번 페이지의 시설 자료 출처와 집계 기준은 [해당 페이지 하단](03-safety-elements.html)에 링크되어 있습니다.

페이지는 이 디렉터리의 상대 경로로 자산을 읽습니다. 저장소의 다른 경로로 HTML만 따로 옮기면 지도 데이터가 로드되지 않습니다.
