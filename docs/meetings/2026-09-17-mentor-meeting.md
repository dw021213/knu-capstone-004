- 참석: 이대규 책임연구원(멘토), 김동우, 이민환, 서예은, 안동균 (배병윤 불참)
- 자료: 260917_산학협력프로젝트_QnA.hwp, 2026년 제노바이츠 사업소개.pptx, 시연 영상

## 확정 사항
- 최종 사용자: 제주도민 또는 제주 방문객
- 위험 분석 입력: 교통사고 이력 · 기상 · 주변 시설 유무 우선. 우선순위는 예측 모델 단계에서 결정
- 공간 단위: 행정동은 편차가 커서 격자 기반 정제·표준화
- 시간: 현재 위험도 표시 필수, 향후 시점 예측은 되면 좋음
- 산출물·성공 기준: 안전 분석 시각화 결과물
- 일정: 위험 예측 모델 / 시각화 투트랙 병행, 10월 중순까지 가시적 초안 확정
- 개발 방식: 기업 서비스 위에 얹지 않고 팀이 별도 웹앱으로 개발해도 됨. 좋은 부분은 기업이 이후 마이그레이션 검토
- 저장소: 팀 GitHub로 진행, 추후 공유. 공개 범위는 진행 상황에 따라 결정
- API 키: 공공 API·기상청은 무료, 지도는 카카오(일 10만 건). 개인 발급으로 진행 가능
- 정기 회의: 최대한 학교 가이드(주 1회)에 맞춤
- 예상 성과: 논문 방향 긍정
