# 데이터 출처

이 앱이 화면에 보여 주는 데이터의 출처, 버전, 가공 방법을 적습니다. 데이터를 바꾸면 이 문서도 같은 커밋에서 고칩니다.

## 위험도 점수

| 항목       | 내용                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------- |
| 이름       | 도로 특성 기반 상대 교통사고 위험도                                                          |
| 제공       | 안동균(교통 모델) 전달본                                                                     |
| dataset_id | `jeju_h3_r8_road_islands_its20260914_ngii2025_v1`                                            |
| 생성 시각  | 2026-10-12 09:47:48 (KST, `metadata.json`의 `generated_at`)                                  |
| 격자       | H3 해상도 8, 3,651개 셀(우도·추자도 포함)                                                    |
| 본섬 도로  | 표준노드링크 2026-09-14 배포 파일. 날짜는 파일명상 배포일이며 실제 측량일이 아님             |
| 섬 도로    | 우도·추자도는 국토지리정보원 수치지도(2025년 제작). 도로 길이·밀도·도로선 수 3개 변수만 사용 |
| 모델       | 도로 전용 CatBoost(깊이 6, 시드 42·52·62 앙상블). 학습 2017~2019, 검증 2020, 평가 2021       |
| 셀 구성    | 표준노드링크 기반 2,200개, 수치지도 보완 49개, 도로 자료 미확인 1,402개                      |

### 점수의 뜻

- 날짜와 무관한 공간 점수입니다. 날짜·날씨·교통량·사고 이력을 입력하지 않았으므로 날짜를 바꿔도 값이 같습니다.
- 사고확률이 아닙니다. 백분위는 도로 자료가 있는 셀 2,249개 안에서 매긴 상대 순위(0~100)이고, 높을수록 상대적으로 위험합니다. 백분위 95는 사고확률 95%라는 뜻이 아닙니다.
- 2026년 실제 사고 자료로 정확도를 검증하지 않았습니다. `metadata.json`의 2021년 지표는 과거 평가 값이라 지금의 정확도로 쓰지 않습니다.
- 본섬과 섬의 도로 자료는 둘 다 "2026년 도로 자료"라고 표시하지 않습니다.

### 화면 표시

- 백분위를 5단계로 나눕니다: 90 이상 매우 높음, 70 이상 높음, 30 이상 보통, 10 이상 낮음, 그 아래 매우 낮음.
- 백분위가 빈 1,402개 셀은 데이터 부족으로 회색 빗금을 칩니다. 도로 자료를 확인하지 못했다는 뜻이며 안전하다는 뜻이 아닙니다.

### 파일과 가공

| 파일                          | 설명                                                                                                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `data-src/risk_scores.csv`    | 전달받은 `risk_scores.csv`를 고치지 않고 그대로 둔 원본                                                                                                                  |
| `data-src/risk_metadata.json` | 같은 전달본의 `metadata.json` 정제본. 제공자 PC의 절대경로 값(`model_source`, `model_files[].path`, `input_sources.*.path`)만 파일 이름으로 줄이고 다른 값은 원본 그대로 |
| `public/data/scores.json`     | `npm run data:scores`(`scripts/build-scores.mjs`)로 만든 배포용 파일. 셀마다 `[백분위, 도로 출처 코드]`만 남김                                                           |

`scores.json` 가공 규칙:

- 백분위는 소수 둘째 자리에서 반올림합니다. 빈칸은 `null`입니다.
- 도로 출처 코드는 `ITS_standard_nodelink` → 1(표준노드링크), `NGII_digital_map` → 2(수치지도), `no_mapped_road` → 0(미확인)입니다.
- 원본의 `risk_score`(보정하지 않은 모델 점수)는 싣지 않습니다. 도로 자료가 없는 셀에도 값이 있어 안전 판단에 쓰면 안 되기 때문입니다.

### 백엔드 모드(`VITE_DATA_MODE=api`)

백엔드 `/api/grid`의 `hazard_percentile`(유동인구를 끈 교통 모델 백분위)로 색을 칠합니다. `risk_percentile`(유동인구 반영)과 `risk_score`는 읽지 않습니다. 격자 응답에는 표준노드링크·수치지도 구분이 없어서 같은 버전의 `scores.json`에서 도로 출처를 붙입니다.
